✨ LUMINAVERSE - The Shining Universe of Knowledge ✨

A modern next-generation multi-field platform for creating, reading, updating, and deleting articles.
Built with React 18, TypeScript, Tailwind CSS, and Vite.
Features a CLEAN, SIMPLE design with ADVANCED GEOMETRIC SHAPES!

🚀 QUICK START:

1. Install dependencies:
   npm install

2. Start development server:
   npm run dev

3. Build for production:
   npm build

📁 PROJECT STRUCTURE:
src/
  ├── components/       # Header, ArticleCard components
  ├── hooks/           # useArticles for state management
  ├── pages/           # Home, Detail, Create, Edit pages
  ├── types/           # FieldType, Article interfaces, Field Info
  ├── App.tsx          # Main app with field routing
  ├── main.tsx         # React entry point
  └── index.css        # Tailwind + custom animations

🎯 FIELD SYSTEM:
Each field has:
- Unique color gradient (cyan, purple, green, pink, orange, red, blue, yellow, violet)
- Custom emoji icon
- Field-specific categories
- Description text
- Color-coded filters and badges

💾 DATA PERSISTENCE:
- Uses browser's localStorage
- Articles automatically saved and loaded
- Comes with 6 sample articles across different fields
- Data persists between sessions

📝 ARTICLE STRUCTURE:
- Title: Main article heading
- Excerpt: Brief summary shown in card
- Content: Full article text
- Author: Writer's name
- Field: Industry/Category (tech, selling, shop, etc.)
- Category: Sub-category within the field
- Date: Publication date (auto-generated)
- Read Time: Estimated reading duration

🎯 USER FLOWS:
1. SELECT FIELD: Choose from 9 different industries
2. BROWSE: View articles filtered by selected field
3. SEARCH: Find articles by title, author, or content
4. CREATE: Write new article with field-specific categories
5. READ: View full article with field-colored styling
6. EDIT: Update article details and content
7. DELETE: Remove articles with confirmation
